Deployment Highlights

  • Serverless Express on Netlify
    Bundled the full Express API into a single CommonJS function (api.cjs) with lazy init — no Vite deps at runtime.
    → 2.2 MB self-contained function artifact
  • Session store in Lambda
    connect-pg-simple tried to read table.sql from disk — unavailable in /var/task.
    → Inline SQL session table creation via Neon pool
  • Neon + serverless constraints
    WebSocket DB driver and multi-statement queries fail in Netlify functions.
    → poolQueryViaFetch + split SQL statements
  • Build pipeline
    NODE_ENV=production skipped devDependencies needed by Vite/esbuild.
    → NPM_CONFIG_PRODUCTION=false in netlify.toml
